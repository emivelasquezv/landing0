# COLLINS · LANDING 0€

Página de solicitud de la promoción LANDING 0€ (5 plazas hasta el 5 de octubre de 2026).

- `index.html`: la landing con el formulario.
- `privacidad.html`: política de privacidad.
- `landing0.js`: `PLAZAS_LIBRES` (contador) y `FORM_ENDPOINT` (URL de Google Apps Script).
- `google-sheets.gs`: script que guarda las solicitudes en Google Sheets (instalación en `GOOGLE-SHEETS.md`).

Publicada con GitHub Pages desde la rama `main`.
